 📱 Mobile Sales Dashboard

 📌 Project Overview

- Developed an interactive **Mobile Sales Analytics Dashboard** using **Power BI**
- Designed to analyze:
  - 📈 Sales trends
  - 🏙️ City-wise performance
  - 💳 Payment methods
  - 📅 Monthly & yearly comparisons
  - 📦 Brand performance
---
# 🎯 Business Problem

Businesses often face challenges in:

- Tracking sales performance across time periods
- Comparing current sales with previous year sales
- Identifying top-performing mobile brands
- Understanding customer payment preferences
- Monitoring regional sales trends
- Analyzing transaction behavior efficiently

This dashboard helps solve these problems through interactive analytics and reporting.
---

# 🛠️ Tools & Technologies Used
